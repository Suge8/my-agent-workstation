# 视频布局

观看视频的方式与阅读网页的方式不同。设计是为了从全框架中快速理解，而不是为了奖励仔细检查的密集 UI。

## 从框架开始

- 决定观众在每个场景中首先应该注意到的内容。围绕这一件事构建框架。
- 将重要内容保存在宽敞的安全区域内。对于 1080 像素宽的视频，关键文本与侧面的距离至少为 80 像素，与顶部和底部的距离至少为 100 像素。
- 喜欢居中、堆叠或强烈对齐的布局。避免分散的仪表板式布局。
- 有意利用空白空间。具有强烈信息的视频帧通常比充满小部件的视频帧更好。
- 不要仅仅因为有空间就将物体并排放置。如果两个元素相互竞争，请依次展示它们或将其中一个元素明确置于次要位置。

## 默认场景结构

对于宣传片、讲解员和动态图形，一个好的默认场景是：

- 一条主要短信
- 一种支持视觉效果，例如图标、产品卡、形状或屏幕截图样式的模型
- 一两个背景强调

避免默认使用许多卡片、徽章、边框、药丸或小标签。这些是 Web UI 模式，通常会让视频感觉混乱。

## 通过施工防止重叠

- 不要使用独立的 `top`、`left`、`right` 或 `bottom` 值手动定位每个可读元素。
- 使用 `flex`、`grid`、`gap`、`justifyContent` 和 `alignItems` 将可读内容放入正常布局容器中。
- 主要对背景、装饰形状、发光、粒子和要分层在内容后面的元素使用绝对定位。
- 为场景中的每个主要元素预留一个位置。例如，垂直促销场景可以使用居中列，其中 `gap` 为标题、卡片，CTA。
- 使用 `opacity`、`transform` 和 `scale` 对保留槽中的元素进行动画处理；不要将它们动画化到被另一个元素占据的空间中。
- 如果元素从屏幕外或从框架的其他部分进入，则其最终静止位置仍必须属于布局槽。
- 当文本长度未知或用户提供时，假设它可能会换行。为文本块提供足够的宽度和垂直空间，而不是在其正下方放置另一个对象。

## 视频中的文字

- 文本必须在视频观看距离下可读。如果不确定，请将其变大，而不是变小。
- 将小文本视为装饰性文本，除非用户明确需要阅读它。
- 对于 1080 像素宽的合成，请使用以下粗略最小值：
  - 主标题：84px
  - 重要支持文字：44px
  - 标签或简短标注：32px
- 使用合成宽度缩放这些值。例如，1920 像素宽的构图需要比 1080 像素宽的构图更大的文本。
- 保持线路长度较短。将长的想法分解为多个场景，而不是缩小字体。
- 在文本和背景之间使用强烈的对比。如果文本难以阅读，请添加微妙的背景形状或简化背景。
- 不要在同一区域堆叠许多文本块。为每条消息赋予自己的时刻或明确分隔的区域。

## 用时间解决拥挤问题

- 让时间解决布局问题。不要一次显示所有功能，而是一个接一个地显示它们。
- 如果框架感觉拥挤，请删除一个元素，放大焦点元素，或将次要元素移动到另一个场景。
- 与分散的 UI 布局相比，更喜欢集中或强烈对齐的组合。
- 使用背景形状、渐变和卡片来支持信息，而不是制造视觉噪音。
- 保持跨场景的视觉系统一致：重复间距、重复对齐和一小组shapes/colors.

## 预渲染检查

在渲染之前，检查正常尺寸的代表性帧：

- 主要信息可以快速阅读吗？
- 有没有一个明显的焦点？
- 是否有任何物体接触、重叠或尴尬地相邻放置？
- 如果看到的时间少于一秒，这个框架仍然有意义吗？
