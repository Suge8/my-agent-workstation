Remotion可以与任何React框架一起使用。

我们提供以下模板：

- Next.js App Router 与 Tailwind：https://github.com/remotion-dev/template-next-app-dir-tailwind. 使用 Lambda 作为默认渲染选择。
- 没有 Tailwind 的 Next.js App Router：https://www.remotion.dev/templates/next-no-tailwind. 使用 Lambda 作为默认渲染选择。
- Next.js 页面路由器： https://github.com/remotion-dev/template-next-pages-dir. 使用 Lambda 作为默认渲染选择。
- Vercel 沙箱渲染： https://github.com/remotion-dev/template-vercel. 使用 Vercel 作为默认渲染选择。
- React 路由器 7：https://github.com/remotion-dev/template-react-router. 使用 Lambda 作为默认渲染选择。
- Express.js渲染服务器：`packages/template-render-server`：https://github.com/remotion-dev/template-render-server.使用Node.js作为默认渲染选择。

这些可以直接克隆，或用作参考。

对于现有应用程序，请参阅 https://www.remotion.dev/docs/brownfield-installation.md.
