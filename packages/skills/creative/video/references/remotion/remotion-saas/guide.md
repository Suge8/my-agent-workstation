# Remotion SaaS

使用 Remotion 构建视频应用程序 - 框架、渲染和播放器建议

人们可以使用 Remotion 来构建应用程序。
可以有一个简单的表单并将其连接到渲染器，或者有一个复杂的视频编辑器。

## 选择模板或框架

我们有几个 SaaS 模板，可以克隆或用作参考。
请参阅[选择框架](framework.md)以获取选择模板或框架的帮助。

## `<Player>`

该组件允许在 React 应用程序中嵌入 Remotion 预览。有关播放器的更多信息，请参见[播放器](player.md)。

## 渲染

有客户端和服务器端渲染选项可用。有关如何选择以及Lambda、Vercel、Node.js 和Cloudflare 选项的建议，请参阅[渲染](rendering.md)。

## 与 Vue

请参阅 https://www.remotion.dev/docs/vue.md 了解如何将 Remotion 与 Vue 一起使用。

## Angular

请参阅 https://www.remotion.dev/docs/angular.md 了解如何将 Remotion 与 Angular 一起使用。

## Svelte

请参阅 https://www.remotion.dev/docs/svelte.md 了解如何将 Remotion 与 Svelte 一起使用。
