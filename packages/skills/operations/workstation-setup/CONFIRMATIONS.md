# 敏感关口

只对当前计划确认；计划变化后重新确认。

- **覆盖或 SYSTEM：** 展示目标、备份位置和将被替换的内容。SYSTEM 单独询问“是否替换 SYSTEM？”，收到明确同意后继续。
- **卸载：** 展示将删除的受管理内容，以及数据、备份和外部依赖的保留选项；用户选定范围并再次确认后继续。
- **权限：** 说明所需 macOS 权限及用途，用户明确同意后让其亲自在系统设置中授权；用户确认完成后再诊断。
- **OAuth：** 说明供应商和授权用途，询问是否开始，再由用户完成登录；不读取或转述令牌。
- **密钥：** 说明供应商和安全输入入口，询问是否配置，再由用户亲自输入；不接收、回显、记录或写入命令行。

仅在用户确认了屏幕上展示的确切计划后，才向控制面传递非交互确认参数。取消、含糊回答或授权未完成都保持未变更状态。
