name: implement
description: "根据规范或一组工单实现一项工作。"
disable-model-invocation: true
---

实现用户在规范或工单中描述的工作。

若本回合关联工单，动手前先按仓库 issue tracker 的约定认领它；工单的关闭由合并触发，不在本技能内手动关闭。

在预先约定的接缝处尽可能使用 /tdd。

定期运行类型检查，定期运行单个测试文件，并在最后运行一次完整测试套件。

完成并验证后，先把本次改动提交到当前分支，再使用 `code-review` skill 发起外部审查，并结束当前回合。提交必须带路径且只含你本次的修改：`git add <你的路径>` 后 `git commit -m <msg> -- <你的路径>`（带路径提交走临时索引，共享 checkout 上不会带上他人已暂存的内容；遇 index.lock 冲突稍候重试），不推送。

审查反馈的修复回合同样：修完验证、同样带路径提交，再结束回合。
