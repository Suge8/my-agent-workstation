### 使用时机

在**所有代码实现与本地验证均已全部完成**（作为交付或提交前的最后一步），或用户明确要求审查时使用。切勿在开发进行中或自测未通过时过早触发。

### 调用方式

使用 bash 运行本目录的 [`request-review.sh`](request-review.sh)。默认直接无参调用（FireReview 会自动提取本次会话上下文与代码改动，审查对象为本次会话中工作内容）。

### 运行机制与自动闭环

运行脚本会在当前会话**挂载后台审查状态机**，仅需在首次发起时调用一次：

- **自动驱动**：当前回合结束后，状态机会在后台自动启动多模型审查与顾问仲裁。
- **自动复审**：审查未通过时，系统会自动注入反馈唤醒修复回合。核实、修复并验证通过后直接结束该回合，系统**会自动推进下一轮复审**，直到通过或达到停止条件。
- **无需重入**：质检流程由状态机全自动闭环，打回修复时**无需再次运行脚本**。
