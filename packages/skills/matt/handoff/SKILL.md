---
name: handoff
description: 将当前对话压缩成交接文档，供另一位代理继续处理。
argument-hint: "下一次会话将用于什么？"
disable-model-invocation: true
---

编写一份交接文档，总结当前对话，以便新的代理继续工作。将其保存到用户操作系统的临时目录，而不是当前工作区。

在文档中加入“建议技能”部分，指明下一位代理应使用哪些技能。

不要重复其他工件（规范、计划、ADR、问题、提交、差异）中已经记录的内容。通过路径或 URL 引用它们，而不是重复内容。

删除任何敏感信息，例如 API 密钥、密码或个人身份信息。

如果用户传入了参数，将其视为下一次会话的工作重点描述，并据此调整文档。
