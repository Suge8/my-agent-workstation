name: research
description: 针对高可信度的一手来源调查问题。当用户希望研究主题、探索方案、收集文档或 API 事实时使用。
---

subagents 工具可用时，按相互独立的子问题拆波委派调查工人：一波并行 5–10 个，模型从选型表挑调研档（廉价并行档），你继续干活。工人产出是线索不是结论——影响决策的主张，由你追至一手来源或交叉验证后才可采信。收割要点后即 kill 工人会话。
工具不可用时亲自调查：直接检索并阅读一手来源，不启动任何后台代理或子进程。

调查纪律（委派或亲自执行相同）：

1. 针对**最新前沿一手来源**调查问题——官方文档、源代码、规范、第一方 API——将每条主张追溯至拥有该主张的来源，卖力调用各类联网搜索工具和本地事实源查询。
2. 调查结论默认写进给用户的回复并附来源，不在仓库留下调查文件。
3. 结论需要沉淀时先与用户对齐去向：有长期价值的按 domain-modeling 技能落进 ADR 或 CONTEXT.md；仅当用户明确要求独立留档时才写单个 Markdown 到仓库既有笔记目录。未经用户确认，不写任何文件。

完成标准：每个子问题都有可引用的一手来源结论，或明确标记"未能证实"；与用户对齐后本轮调查才收口。
