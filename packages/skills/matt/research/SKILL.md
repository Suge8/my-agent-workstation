description: 针对高可信度的一手来源调查问题，结论默认在回复中交付。当用户希望研究某个主题、收集文档或 API 事实时使用。
---

subagents 工具可用时，把调查委派给调查工人——相互独立的子问题可以并行多个工人，你继续干活；
不可用时亲自调查：直接检索并阅读一手来源，不启动任何后台代理或子进程。

调查纪律（委派或亲自执行相同）：

1. 针对**最新前沿一手来源**调查问题——官方文档、源代码、规范、第一方 API、进行研究——而不是它们的二手解读。将每条主张追溯至拥有该主张的来源。卖力调用各类联网搜索工具和本地事实源查询。
2. 调查结论默认写进给用户的回复并附来源，不在仓库留下调查文件。
3. 结论需要沉淀时先与用户对齐去向：有长期价值的按 domain-modeling 技能落进 ADR 或 CONTEXT.md；仅当用户明确要求独立留档时才写单个 Markdown 到仓库既有笔记目录。未经用户确认，不写任何文件。
