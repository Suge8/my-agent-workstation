# 分流标签

这些技能使用五个规范分流角色。本文件将这些角色映射到本仓库 issue tracker 实际使用的标签字符串。

| mattpocock/skills 中的标签 | 我们 tracker 中的标签 | 含义 |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `待评估`             | 维护者需要评估此 issue |
| `needs-info`               | `缺信息`             | 等待报告者提供更多信息 |
| `ready-for-agent`          | `待领`               | 已完整说明，可交给 AFK agent |
| `ready-for-human`          | `需人工`             | 需要人工实现 |
| `wontfix`                  | `不处理`             | 不会处理 |

当技能提到某个角色（例如“应用 AFK-ready 分流标签”）时，使用此表中对应的标签字符串。

编辑右侧列，以匹配你实际使用的词汇。

## 类型标签

同机制映射，供建票技能使用。

| 规范角色 | 我们 tracker 中的标签 | 含义 |
| -------- | -------------------- | ------------------ |
| `spec`   | `Spec`               | 波次 spec，子票挂其下 |

## 生命周期标签

由执行方在认领和放弃工单时维护，流转规则见 `issue-tracker.md` 的工单生命周期。

| 规范角色     | 我们 tracker 中的标签 | 含义 |
| ------------- | -------------------- | ------------------------ |
| `in-progress` | `进行中`             | 已被执行方接管 |
| `blocked`     | `阻塞`               | 被前置工单或定约阻塞，未 ready |
