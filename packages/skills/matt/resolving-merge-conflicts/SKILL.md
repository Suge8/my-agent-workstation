---
name: resolving-merge-conflicts
description: "在需要解决正在进行的 git merge / rebase 冲突时使用。"
---

1. **查看当前状态**——merge / rebase 进行到哪一步。检查 git 历史和发生冲突的文件。

2. **找到每处冲突的第一手来源。** 深入理解每项改动为什么被做出、原始意图是什么。读 commit 消息，查 PR，查原始 issue / 工单。

3. **逐个 hunk 解决。** 尽可能保留双方意图。确实不兼容时，选择与本次合并既定目标一致的一方，并记下这个取舍。**不要**发明新行为。始终解决冲突，绝不 `--abort`。

4. 找出项目的**自动化检查**并运行——通常是类型检查、测试、格式化。修复合并过程中被破坏的任何内容。

5. **完成 merge / rebase。** 暂存全部改动并提交。如果是 rebase，继续推进直到所有 commit 都完成 rebase。
